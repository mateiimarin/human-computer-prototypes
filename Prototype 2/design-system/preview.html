01

Principles

  1. Colour means evidence.The UI is grey. If something is coloured, it says something about understanding, help, or check mode.
  2. Two modes, one look.Work and Verify share components; Verify removes the companion and adds a persistent "references hidden" signal.
  3. Never colour alone.Icon + text + colour for every state. Unverified is dashed so it survives greyscale.
  4. Confidence is not evidence.Self-ratings are neutral signal bars — never traffic-light hues.
  5. One next move.One filled pill per region. Everything else is tonal or ghost.
  6. Say less.No praise, no exclamation marks. Name the point and the next action.
  7. Optional looks optional.Deeper checks, twins and exports are tonal choices — never urgent, never primary.

def max_subarray(nums: list[int]) -> int:
    current = best = nums[0]
    for x in nums[1:]:
        current = max(x, current + x)  # extend or restart
        best = max(best, current)
    return best
